# Техническое описание

## Наименование

Портативный мастер выполнения монтажных работ для Универсал Монтаж.

## Назначение

ПО предназначено для стандартизации подготовки и выполнения монтажных работ: фиксации короткого ТЗ, генерации технологического гайда, расчета связанных материалов, отметки выполненных шагов и экспорта листа задания.

## Архитектура

Приложение реализовано как статический веб-продукт:

- HTML-интерфейс: `start.html`;
- стили: `styles.css`;
- логотип и статические изображения: `assets/`;
- доменная логика, шаблоны работ, расчеты и прогресс: `src/domain.js`;
- CSV-импорт и экспорт: `src/csv.js`;
- настройки внешних ссылок и API: `src/integrations.js`;
- управление интерфейсом и локальным сохранением: `src/app.js`.

Бэкенд-сервер не требуется. Данные сохраняются в `localStorage` браузера пользователя.

## Основные функции

- выбор вида работ;
- фиксация объекта, клиента, размеров и условий;
- флаги ТЗ: улица, уклон, косой дождь, протечка, демонтаж, покраска;
- генерация технологического гайда по выбранному виду работ;
- отметка выполненных пунктов;
- шкала прогресса;
- расчет площади, периметра, длины, герметика, грунта, краски и кронштейнов;
- список материалов;
- сохранение листов заданий;
- экспорт текущего листа и журнала в CSV;
- хранение настроек сайта, Telegram и внешнего API endpoint.

## Виды работ

- оклады на окна;
- гидроизоляция;
- водосточная система;
- сварочные работы;
- жестяные работы;
- сервисные исправления;
- общие монтажные работы.

## Требования

Современный браузер: Chrome, Edge, Firefox, Safari или аналогичный. Интернет нужен только для перехода по внешним ссылкам или отправки данных во внешний API, если такой endpoint настроен.

## Оформление

Интерфейс использует фирменные элементы сайта Универсал Монтаж: логотип, темно-синий `#153e5c`, оранжевый `#ef962a`, светлый фон `#e7eceb` и белые рабочие панели.

## Передача продукта

Для передачи достаточно скопировать всю папку продукта на флешку или другой носитель. Запуск выполняется открытием файла `start.html`.

## Основание предметной модели

В предметной модели учтены публичные материалы канала `@yniversalmontag`: сварочные и жестяные работы, решетки, грунтовка/покраска, монтаж конструкций, гидроизоляция, оклады на окна, водосточная система и сервисные исправления после проблем с водой. Продукт закрывает боль одинакового качества выполнения работ разными сотрудниками и передачи технологических тонкостей новым мастерам.
