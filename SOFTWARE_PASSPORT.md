# Паспорт программного продукта

## Наименование

Универсал Монтаж: мастер выполнения работ.

## Версия

1.0, портативная веб-версия.

## Авторство

ИП Дегтярев Денис.

## Назначение

Программный продукт предназначен для подготовки монтажного задания, выбора вида работ, фиксации условий объекта, расчета связанных материалов и прохождения технологического гайда с отметкой прогресса.

## Формат поставки

Продукт поставляется как портативная папка. Установка не требуется.

Состав:

- `Start-Windows.bat` - запуск на Windows;
- `Запустить программу.cmd` - основной пользовательский запуск на Windows;
- `Start-mac.command` - запуск на macOS;
- `start.html` - основной интерфейс;
- `assets/` - логотип и статические материалы;
- `src/` - программная логика;
- `styles.css` - оформление;
- `sample-data/` - пример данных;
- `README.md` - краткое описание;
- `USER_GUIDE.md` - инструкция пользователя;
- `TECHNICAL_DESCRIPTION.md` - техническое описание.

## Требования

Современный браузер: Chrome, Edge, Firefox, Safari или совместимый. Интернет не требуется для основной работы приложения.

## Порядок запуска

На Windows открыть `Start-Windows.bat`.  
Также можно открыть `Запустить программу.cmd`.  
На macOS открыть `Start-mac.command`.  
Резервный вариант: открыть `start.html` двойным кликом.

## Основные функции

- выбор вида монтажных работ;
- фиксация ТЗ;
- учет условий: улица, уклон, косой дождь, протечка, демонтаж, покраска;
- генерация технологического гайда;
- отметка выполненных шагов;
- шкала прогресса;
- расчет материалов;
- сохранение листа задания;
- экспорт CSV для Excel.
