# Универсал Монтаж: мастер выполнения работ

Портативное офлайн-приложение для подготовки ТЗ, прохождения монтажной работы по шагам, расчета связанных материалов и фиксации прогресса.

## Как запустить

1. Скопировать папку `universal-montage-portable` на компьютер или флешку.
2. На Windows открыть `Запустить программу.cmd` или `Start-Windows.bat`.
3. На macOS открыть `Start-mac.command`.
4. Резервный вариант: открыть файл `start.html` двойным кликом в современном браузере.
5. Выбрать вид работ, отметить условия объекта и пройти технологический гайд.

Сервер, установка зависимостей и интернет не требуются. Данные сохраняются в браузере на том компьютере, где открыто приложение.

## Что делает продукт

- фиксирует короткое ТЗ по объекту;
- строит гайд под выбранный вид работ;
- дает минимальные технологические шаги без лишнего текста;
- считает площадь, периметр, герметик, грунт, краску, кронштейны и основные материалы;
- позволяет отмечать выполненные шаги;
- показывает шкалу прогресса;
- сохраняет листы заданий;
- экспортирует лист задания и журнал в CSV для Excel.

## Состав поставки

- `start.html` - точка запуска приложения.
- `Start-Windows.bat` - запуск приложения на Windows.
- `Запустить программу.cmd` - русскоязычный файл запуска на Windows.
- `Start-mac.command` - запуск приложения на macOS.
- `README_FOR_WINDOWS.txt` - короткая инструкция для получателя архива.
- `SOFTWARE_PASSPORT.md` - паспорт программного продукта.
- `styles.css` - оформление интерфейса.
- `assets/logo.png` - логотип Универсал Монтаж.
- `src/domain.js` - шаблоны работ, расчеты, шаги и прогресс.
- `src/app.js` - управление интерфейсом.
- `src/csv.js` - импорт и экспорт CSV.
- `src/integrations.js` - внешние ссылки и API-заготовка.
- `sample-data/requests.csv` - пример файла для импорта.
- `USER_GUIDE.md` - инструкция пользователя.
- `TECHNICAL_DESCRIPTION.md` - техническое описание.
- `tests/product.test.mjs` - автотесты ключевых функций.

## Проверка

```bash
npm test
```

Тесты проверяют CSV, нормализацию записей, генерацию гайда, расчеты материалов и прогресс выполнения.
