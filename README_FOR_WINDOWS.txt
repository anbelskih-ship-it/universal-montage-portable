Универсал Монтаж - мастер выполнения работ

Как запустить на Windows:

1. Распакуйте архив в любую папку.
2. Откройте папку "Универсал Монтаж - Мастер работ".
3. Запустите файл "START.cmd".

Если Windows покажет предупреждение, нажмите "Подробнее" -> "Выполнить в любом случае".

Программа откроется через самодостаточный файл UniversalMontage-WorkGuide.html.
Для запуска отдельным app-окном можно использовать START_APP_WINDOW.cmd.

Интернет для основной работы не требуется.
