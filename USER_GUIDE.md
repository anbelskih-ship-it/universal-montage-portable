# Инструкция пользователя

## Назначение

Приложение помогает менеджеру или мастеру быстро подготовить лист работ: выбрать операцию, отметить условия объекта, получить расчет материалов и пройти работу по чек-листу.

## Работа с ТЗ

В блоке `1. ТЗ` выберите вид работ и заполните только нужные поля: клиент, объект, размеры, количество, длину швов и условия. Условия отмечаются галочками: улица, уклон, косой дождь, протечка, демонтаж, покраска.

## Гайд

Блок `2. Гайд` автоматически перестраивается под выбранный вид работ. Каждый пункт можно отметить как выполненный. Прогресс виден в процентах и в формате `выполнено/всего`.

## Расчет

Блок `3. Расчет` показывает связанные параметры: площадь, периметр, длину, расход герметика, грунта, краски, количество кронштейнов и список материалов.

## Сохранение и экспорт

Кнопка `Сохранить лист` добавляет текущую работу в журнал листов заданий.  
Кнопка `Экспорт листа` сохраняет текущий лист задания в CSV.  
Кнопка `Экспорт CSV` сохраняет журнал листов заданий для Excel.

## Настройки

В разделе `Настройки` можно указать название, ответственного, сайт, Telegram и адрес внешнего API. Если API не задан, приложение работает полностью локально.
